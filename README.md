# SpendSmart — NumPy Expense Analyzer

SpendSmart is a beginner-friendly Python project that analyzes personal expenses using NumPy.

## Features
- Store and display daily expenses
- Calculate total and average spending
- Find the highest and lowest expense
- Check spending against a budget
- Filter expenses above a chosen amount
- Analyze expenses by category
- Calculate category-wise spending percentages
- Generate a final expense report

## Technologies Used
- Python
- NumPy
- Jupyter Notebook

## How to Run
1. Download `spreadmart.ipynb` from this repository.
2. Open it in Jupyter Notebook.
3. Install NumPy if needed using `pip install numpy`.
4. Run the notebook cells.

## Learning Goals
This project demonstrates NumPy arrays, numerical calculations, filtering, and basic data analysis.
